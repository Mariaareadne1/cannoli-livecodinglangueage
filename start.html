How to use cannoli~

cannoli is a way to make music by writing code. It runs real Strudel, in this web page and in your terminal, with a few additions of its own.

Your first sound

  1. Open the editor and type this line: 
    kick: s("bd*4")
  2. Press ctrl enter to play. On a Mac you can use cmd enter.
  3. Change the code and press it again. You hear the change right away.
  4. Press ctrl . to stop.

A whole song

key a minor
tempo 124

kick: beat("fourfloor").s("bd")
hats: s("hh*8").gain(.4)
bass: n("0 ~ 3 5").s("sawtooth").octave(2).lpf(700)
lead: n("0 2 4 7").s("triangle").every(4, rev).bloom(.5)
key a minorEvery n() follows this key, so the parts fit together.
tempo 124The speed, in beats a minute.
kick:A name for the part. Call it anything.
beat("fourfloor")A named rhythm. The reference lists them all.
.s("bd")The sound to play.
.gain(.4)Each change is chained on with a dot.

Tools in the web editor

Everything you click writes code, so you can always read what changed.

kitAll your drums on one grid, lined up by beats. Click steps, press M to mute, or add a drum.
mixMute any part and slide its effects. Slide an effect back to off to remove it from the code.
timelineChoose which cycles each part plays in.
referenceEvery word you can write, with lines to copy.
controlOpen terminal windows from this page.
under a linePut the cursor on a pattern, sound, chord, key or number to get a grid or slider right there.

Set up the terminal

You need Node.js. In the project folder, run:

npm install
npm run web

Then visit localhost:5460 and open the control tab. Choose a song and a look, then press open on the window you want. The first time, your Mac asks to let it control Terminal. Allow it.

Terminal windows

EverythingAll five windows, side by side.
Code editorWrite and play. This is the one that makes the sound.
GuideExplains the line you're on.
ReferenceEvery word in the language.
VisualA shark that moves with the music.
ThreadsWhat each part plays this bar.

Choose plain terminal as the look for no colours and no background, just your terminal as it is.

Keys in the terminal editor

ctrl sPlay, or apply your changes.
ctrl tStop at the end of the bar.
ctrl dDrum kit.
ctrl xMixer: mute and effects.
ctrl lSong timeline.
ctrl bMove the keyboard into a grid, or back to the code.
ctrl gNext theme.
ctrl qSave and quit.

Muting a part

Put an underscore in front of its name, or press M in the kit or mix tab:

_kick: s("bd*4")
